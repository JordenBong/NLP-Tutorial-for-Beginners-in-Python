# 📚 NLP Tutorial for Beginners in Python
🔗 Based on the [codebasics](https://www.youtube.com/playlist?list=PLeo1K3hjS3uuvuAXhYjV2lMEShq2UYSwX)

This repository contains my implementations of core NLP concepts from the YouTube codebasics tutorial series, covering text preprocessing, word embeddings, and real-world text classification using Python.

## 🔍 Key Concepts Covered
1. **Text Preprocessing**
   - Regex-based cleaning 
   - Tokenization, stopwords removal, stemming/lemmatization 
   - POS Tagging
   - Named Entity Recognition
   

2. **Word Vectorization**
   - Bag-of-Words and TF-IDF
   - Word2Vec: Continuous BOW, Skip-Gram
   - GloVe 
   - fastText 


3. **NLP Tools / Libraries**
   - re
   - NLTK
   - spaCy
   - gensim
   - fastText


4. **Real-World Text Classification**
   - Spam detection
   - Fake / Real news detection
   - News topic classification
   - Custom Domain training via fastText
